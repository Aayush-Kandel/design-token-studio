# Design Token Studio

Client-side CSS variable, color palette, and spacing generator.

GitHub Pages link:
    https://aayush-kandel.github.io/design-token-studio/

Hard demands
- Zero Markup: `index.html` has an empty `<body>`; everything mounts from `app.js`.
- Web Component: Built as `<token-studio>` using `customElements.define` and Shadow DOM.
- No Ifs: Zero `if`, `switch`, or ternary (`? :`) operators anywhere in the code.
